# Web Scraping Mini Project

A beginner-friendly web scraping project built using Python.

## Technologies Used

- Python
- Requests
- BeautifulSoup
- Pandas
- Jupyter Notebook

## Data Extracted

- Product Name
- Price
- Rating
- Stock Status

## Practice Website

https://scrapifydatalabs.com/playground/static-products/

## Project Workflow

Website → Requests → BeautifulSoup → Structured Data → Pandas DataFrame → CSV
